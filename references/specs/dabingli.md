# 大病历书写规范（结构化）

> 来源：《大病历书写要求》PDF（7 页）＋《实习病历考核表》。书写参照人卫第八版《诊断学》格式。
> 本文件把原文的口语化要求拆成**可执行、可机检**的规则。`scripts/spec_lint.py` 检查其中标注 `[机检]` 的条目。

---

## 一、格式要求（原文 5 条）

| 编号 | 规则 | 机检 |
|---|---|---|
| R01 | 蓝黑笔书写，非蓝黑笔一律重写 | — |
| R02 | 首行空两格；需另起一行的一定要另起一行 | 部分 |
| R03 | **既往史、个人史、婚育史、家族史不另起一行**：各自起段、首行空两格，但**段间不留空行**（解读已确认，见第七节 Q1） | `[机检]` |
| R04 | **系统回顾另起一行**；各系统前**不可标数字**；<7 岁可不写 | `[机检]` |
| R05 | 各部位均需写全，不可漏写 | `[机检]` |
| R06 | 心脏叩诊**三线表必须画**；表下写"注：左锁骨中线距胸骨中线……" | `[机检]` |
| R07 | 儿科参照儿科标准，但三线表必须画 | — |

> **格式一处错即重写。** 这是这份规范最狠的一条，所以 R01–R06 优先于任何内容优化。

## 二、内容要求（原文 9 条）

| 编号 | 规则 | 机检 |
|---|---|---|
| R08 | 过敏史：**有则用红笔**，无则蓝黑笔写"无" | `[机检]` |
| R09 | 病历首页基本信息写全，**不可出现空项** | `[机检]` |
| R10 | 三线表数据保留**两位有效数字**，小数点后**只可为 0 或 5** | `[机检]` |
| R11 | 淋巴结写出**所有体表浅淋巴结**，不可漏写 | `[机检]` |
| R12 | 神经反射写出**所有反射**，不可漏写 | `[机检]` |
| R13 | 错字斜线划掉接着写，同页不超 3 处；事后发现用红笔划去并在右上方写正确内容＋时间、见习医生、姓名 | — |
| R14 | 辅助检查须注明**医院、检查、时间、结果**，格式：`胸部平片（2017-01-01，北京人民医院）示：消化道穿孔。` | `[机检]` |
| R15 | **病名、药名及诊断疾病名带引号** | `[机检]` |
| R16 | **入院诊断靠右写** | `[机检]` |

> 内容要求同页不可超 3 处，超了也要重写。

## 四、各章节必写项目

### 主诉（R17）

- **20 字以内**，症状 + 持续时间
- 不写诊断名，不写检查结果

### 现病史（R18）

必须覆盖以下要素，缺一即算内容不全：

| 要素 | 说明 |
|---|---|
| 首次发作情况 | 起病时间、缓急 |
| 诱因 | 有无诱因，具体是什么 |
| 性质 | 胀痛 / 绞痛 / 烧灼样 / 撕裂样…… |
| 阵发性或持续性 | 明确写出 |
| 程度 | 能否忍受、是否影响睡眠 |
| 与进食或体位的关系 | 有无缓解/加重体位 |
| 是否影响活动 | 行走、弯腰、翻身 |
| 伴随症状 | 阳性症状 + **有意义的阴性症状** |
| 缓解方式 | 自行用药、休息、体位 |
| 用药 | **他人叙述的药名必须加引号**，写明效果 |
| 检查及结果 | 做过何种检查、在哪做、结果 |
| 一般情况 | 神志、精神、睡眠、食欲、大小便、体重改变、**体力变化** |

- **时间不能用英文缩写**：写"1 天""5 小时"，不写"1d""5h"

### 既往史（R19）

平素健康状况 → 否认"结核""肝炎""疟疾"等传染病及密切接触史 → 否认"高血压"（时间、治疗及控制情况）→ 否认"糖尿病" → 否认"心脏病" → 否认"脑血管疾病" → 否认输血史、无献血史 → 无手术外伤史（何时、何地、治疗情况）→ 否认药物过敏史（过敏表现、缓解方式）→ 否认食物过敏史 → 预防接种史随当地计划免疫

### 系统回顾（R04）

**8 个系统，顺序固定，各系统前不标数字：**

1. 呼吸系统
2. 循环系统
3. 消化系统
4. 泌尿生殖系统
5. 造血系统
6. 内分泌系统及代谢
7. 神经精神系统
8. 肌肉骨骼系统

阴性表述照模板写全（如"无慢性咳嗽、咯痰、咯血史……"），不能只写"各系统无特殊"。

### 个人史（R20）

生长于原籍 → 文化程度 → 无外地长期居住史（地点及年限）→ 无疫区疫水接触史 → 无工业粉尘、毒物、放射性物质接触史 → 无牧区、矿山、高氟区、低碘区居住史 → 生活规律 → 否认吸毒史 → 吸烟史（多少年、每日多少支、是否戒烟）→ 饮酒史（多年、每日折合酒精约多少 g）→ 否认冶游史

### 月经生育史（R21）

按人卫第八版《诊断学》P566 格式：月经来潮年龄、周期、经期、末次月经、月经量、有无血块、有无痛经（中度痛经需说明是否影响日常活动）→ 孕 __ 产 __ → 足月妊娠分娩方式（如"因'胎膜早破'剖宫产 1 男活婴"）→ 无流产、死产、难产 → 育有 __ 子女

### 家族史（R22）

父亲体健（曾患疾病及治愈情况；去世原因、年龄）→ 母亲体健 → 兄弟姐妹 → 子女 → 家族无遗传病病史

### 体格检查（R05）

| 部位 | 必写内容 |
|---|---|
| 一般状况 | 发育、营养、神志、体位、面容、表情、查体是否合作 |
| 皮肤、黏膜 | 弹性、皮温、颜色、皮疹、皮下出血、结节肿块、蜘蛛痣、肝掌、瘢痕、溃疡、毛发 |
| 淋巴结 | **全部体表浅淋巴结**（见下） |
| 头颅 | 大小、形状、肿块、压痛、瘢痕、头发 |
| 眼 | 眉毛、睫毛、眼睑、眼球、结膜、巩膜、角膜、瞳孔（大小、等圆）、对光反射、辐辏反射 |
| 耳 | 耳廓、外耳道分泌物、乳突压痛、听力 |
| 鼻 | 外形、分泌物、鼻翼扇动、鼻中隔、鼻窦压痛 |
| 口腔 | 气味、张口呼吸、口唇、龋齿/义齿/残根、牙龈、舌、苔、咽、腭垂、扁桃体、发音 |
| 颈部 | 对称、活动、气管位置、甲状腺（分度/硬度/压痛/结节/震颤/杂音）、颈静脉、肝颈静脉回流征、颈动脉搏动 |
| 胸部 | 胸廓对称性、压痛、肋间隙、呼吸频率与节律、乳房、胸壁静脉/皮下气肿 |
| 肺 | 视诊、触诊（呼吸动度、胸膜摩擦感、语颤）、叩诊（清音、肺下界三线、移动度）、听诊（呼吸音、啰音、胸膜摩擦音、语音传导） |
| 心脏 | 视诊（心尖搏动位置/范围）、触诊（震颤、抬举样搏动、心包摩擦感）、叩诊（**三线表**）、听诊（心率、心律、心音、A2 与 P2、分裂、附加音、杂音、心包摩擦音） |
| 桡动脉 | 脉搏频率、节律、搏动、奇脉、交替脉 |
| 周围血管征 | 毛细血管搏动、枪击音、水冲脉、动脉异常搏动 |
| 腹部 | 腹围（腹水/包块时测）、视诊、触诊（腹壁、压痛反跳痛、液波震颤、肿块、肝、胆囊 Murphy、脾、肾、膀胱、输尿管点）、叩诊（肝上界/下界/上下径、肝区叩击痛、肾区叩击痛、移动性浊音、胃泡鼓音区）、听诊（肠鸣音、振水音、血管杂音） |
| 肛门直肠 | 未发现异常（或未检查） |
| 外生殖器 | 未发现异常（或未检查） |
| 脊柱 | 形态、活动度、压痛、叩击痛 |
| 四肢 | 形态、杵状指趾、静脉曲张、肌肉萎缩、肌张力、下肢水肿、关节 |
| 神经系统 | 见下，**不可写"……未引出"** |

**淋巴结必须写全（R11）：**
耳前、耳后、枕部、颌下、颈前、颈后、锁骨上、腋窝（尖群、中央群、胸肌群、肩胛下群、外侧群）、滑车上、腹股沟（上群、下群）、腘窝

**神经反射必须写全（R12）：**

| 类别 | 项目 |
|---|---|
| 浅反射 | 角膜反射、腹壁反射、提睾反射 |
| 深反射 | 肱二头肌反射、肱三头肌反射、膝腱反射、跟腱反射 |
| 病理反射 | Babinski 征、Oppenheim 征、Gordon 征、Chaddock 征、Hoffmann 征 |
| 脑膜刺激征 | 颈强直、Kernig 征、Brudzinski 征 |

### 专科情况

有则写，没有则不写。文字叙述型首行空两格；表格型居中书写。

### 辅助检查（R14）

格式固定：`检查名称（YYYY-MM-DD，医院名称）示：结果。`
例：`胸部平片（2017-01-01，北京人民医院）示：消化道穿孔。`

### 病例摘要（R23）

≤300 字。句式：
`患者×××，性别，年龄，主因"……"入院。` → 现病史概括与特点 → 体格检查（生命体征、双肺、心率心律、腹部、肝脾、生理反射、病理反射）→ 专科检查 → 实验室及辅助检查（**只写异常值**）

### 入院诊断（R16）

靠右书写，编号排列，病名加引号。

## 五、心脏叩诊三线表规范

参照人卫第八版《诊断学》P149（儿科参照《儿科学》P33）。居中绘制。

| 右（cm） | 肋间 | 左（cm） |
|---|---|---|
| 2.0 | Ⅱ | 2.5 |
| 2.0 | Ⅲ | 3.5 |
| 3.0 | Ⅳ | 5.0 |
| — | Ⅴ | 7.0 |

注：左锁骨中线距胸骨中线为 8.0 cm。

**数值规则（R10）**：保留两位有效数字，小数点后只能是 `0` 或 `5`。
→ `2.0` `2.5` `3.5` `5.0` `7.0` `8.0` 合法；`2.3` `3.75` `5.25` 不合法。

## 六、考核表对应关系

《实习病历考核表》按 5 个维度打分，共 100 分：

| 维度 | 分值 | 对本 skill 的要求 |
|---|---|---|
| 病历书写 | 30 | 章节齐全、格式合规、无漏项（R01–R23） |
| 体格检查及操作 | 30 | 淋巴结、神经反射、三线表、各部位写全 |
| 问诊 | 20 | 现病史覆盖全部要素（R18）、系统回顾 8 系统齐全 |
| 初步诊断 | 10 | 入院诊断靠右、病名加引号、编号 |
| 处方医嘱 | 10 | 模板未列此节；**经确认学校不要求，输出不补"诊疗计划"**（见第七节 Q3） |

> 说明：PDF 模板止于"入院诊断 + 见习医生 + 带教老师"，考核表却有"处方医嘱（10 分）"。这是规范自身的不一致。已确认的处理方式是**以 PDF 模板为准、不补章节**，但写规范时仍需知道该评分项存在——若带教老师另行要求，再补"诊疗计划"。
