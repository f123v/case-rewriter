# 改写矩阵 · 完整版

判断一个字段能不能动，查这里。核心原则只有一句：

> **改写改变的是"谁得了这个病、什么时候、在哪家医院"，不改变"这个病怎么发生、怎么被认出来、怎么好转"。**

---

## 一、必须保留（临床骨架）

改动这些，病例就从"教学材料"退化成"文字游戏"。

### 1. 主诉的核心症状与病程性质

| 属性 | 为什么不能动 |
|---|---|
| 核心症状 | 换掉就不是同一个病。腹痛→胸痛，阑尾炎变心梗 |
| 定位与性质 | "转移性"、"持续性胀痛"、"撕裂样" 是疾病指纹 |
| 病程性质 | 急性/慢性、进行性/间歇性、发作性/持续性——决定鉴别方向 |

**可以动的**：时长数值（在病程性质允许的范围内）、症状的形容词程度（剧烈→明显）。

### 2. 关键阳性体征

决定诊断的那几个体征必须留着。删一个，诊断依据就缺一条。

> 反例：急性阑尾炎改写成"右下腹压痛（+）"，把"反跳痛、肌紧张"删了——诊断从"化脓性伴局限性腹膜炎"掉回"单纯性"，但诊断栏没改。

### 3. 有鉴别意义的阴性体征

**这是最容易被误删的部分。** 阴性体征存在的意义不是"记录正常"，而是"排除某个鉴别诊断"。

| 阴性体征 | 排除的疾病 |
|---|---|
| Murphy 征阴性 | 急性胆囊炎 |
| 移动性浊音阴性 | 腹腔积液 / 出血 |
| 肝浊音界存在 | 消化道穿孔 |
| 双下肢无水肿 | 心源性、肾源性因素 |
| 病理征阴性 | 中枢神经系统病变 |

改写时若确实要删，必须同步删掉对应的鉴别诊断条目——否则鉴别诊断变成"凭空的自我否定"。

### 4. 决定诊断的那一项检查

每份病例通常有一项"钥匙检查"：CT 见阑尾增粗、肌钙蛋白升高、病理报告。它的**结果方向**（阳性/阴性）和**定性结论**不能改。

可以改的：具体数值（在阈值同侧扰动）、描述措辞、检查顺序。

### 5. 治疗与转归的因果对应

"做了什么 → 结果如何"这条链不能断、不能反。

> 反例：原病例"急诊手术后第 5 天出院"，改写成"予抗生素保守治疗 3 天后症状加重转手术"——但转归仍写"第 5 天愈合出院"，中间那段恶化没人处理。

## 二、可以替换（表型变量）

### 人口学

| 维度 | 安全区 | 危险区 |
|---|---|---|
| 年龄 | 同年龄段内 ±15 岁 | 跨越好发年龄分层（如儿童肠套叠 ↔ 成人肠梗阻） |
| 性别 | 疾病无性别特异性时可翻转 | 涉及妊娠、前列腺、妇科、乳腺、睾丸扭转时必须重写相关章节 |
| 职业 | 与暴露无关时可自由 | 尘肺、职业性耳聋、农药中毒等职业相关病不可改 |
| 民族 | 一般可改 | 地中海贫血、G6PD 缺乏等遗传病相关时不可改 |
| 婚育史 | 随年龄性别同步调整 | 不能只改年龄忘了改"G2P1" |

**改了年龄/性别，必须连带检查**：婚育史、肿瘤标志物参考区间、用药剂量、麻醉风险评估、合并症谱（32 岁不该有"前列腺增生"）。

### 时间轴

| 操作 | 规则 |
|---|---|
| 整体平移 | 所有日期加同一个 delta，**相对间隔完全不变** |
| 改变粒度 | "3 天" → "72 小时" 可以；"3 天" → "3 周" 需重新评估疾病分期 |
| 时间锚点 | 统一用"入院前 X 天"或统一用绝对日期，不要混用 |

**校验方法**：把现病史里的所有"X 天/小时前"按顺序转成小时数，必须**单调不增**（从最早写到最近）。出现递增即为倒序，`lint_case.py` 会报 `timeline` 警告。

### 地区与机构

换医院等级时，**必须同步调整诊疗能力**：

| 机构等级 | 可做的检查 | 不可出现的描述 |
|---|---|---|
| 三级医院 | CT/MRI、ERCP、介入、术中冰冻 | — |
| 二级医院 | X 线、超声、常规生化、基础手术 | 增强 CT、ERCP、PET-CT |
| 社区/乡镇 | 血常规、尿常规、心电图、X 线 | CT、专科手术、病理 |

> 反例：把"某三甲医院"改成"某社区卫生服务中心"，正文却仍写"行腹部增强 CT 及急诊腹腔镜手术"——机构与能力不匹配，一眼假。

### 检验数值

**先确认阈值，再扰动。** 每个指标都有决定临床判断的 cut-off：

| 指标 | 常见决策阈值 | 扰动禁区 |
|---|---|---|
| WBC | 10×10⁹/L（升高）、4×10⁹/L（降低） | 不得从 >10 降到 <10 却仍写"白细胞升高" |
| N% | 75% | 同上 |
| Hb | 男 130 / 女 115 g/L | 不得跨过贫血线却仍写"无贫血" |
| CRP | 10 mg/L | — |
| 肌钙蛋白 | 各院上限（高敏法） | 跨过即为心梗，不可随意降 |
| D-二聚体 | 0.5 mg/L FEU | 跨过即需考虑栓塞 |
| 阑尾直径 | 6 mm | <6 mm 不支持阑尾炎 |
| 胆总管内径 | 8 mm（>8 为扩张） | — |

安全做法：**同侧扰动 ±20%**，改完回头读一遍诊断句是否还成立。

### 合并症与用药

- 同类替换（头孢曲松 → 头孢噻肟）安全，但要保持**给药途径与频次合理**
- 新增合并症必须同步：禁忌证、相互作用、剂量调整、转归影响
- 新增"2 型糖尿病"却不提血糖管理、不调整切口愈合评价 —— 常见硬伤

### 叙述与措辞

自由。但去掉**评价性、追责性**表述：

| 原表述 | 改为 |
|---|---|
| 外院处理不当 | 外院予对症处理后症状无缓解 |
| 延误治疗 3 天 | 症状持续 3 天后就诊 |
| 误诊为胃炎 | 曾按"胃炎"治疗，效果不佳 |
| 患者不配合 | 患者未规律服药 |

## 三、禁止（越界即失真）

### 1. 为凑诊断新增关键阳性发现

想改成"阑尾炎穿孔"，就必须**重写**体征（全腹压痛、板状腹）、影像（游离气体、积液）、手术记录（脓性渗出）。不能只在诊断栏加"穿孔"两个字。

### 2. 拼凑型疑难病例

把两种疾病的典型特征各取一半，造出"既有阑尾炎又有输尿管结石"的病例，但两条证据链都不完整。真正的疑难病例是**证据冲突**，不是**证据堆叠**。

### 3. 改自然史不改诊断

| 改动 | 必须连带 |
|---|---|
| 3 天自愈 → 3 周恶化 | 诊断改（单纯性 → 化脓性/坏疽性）、治疗改、转归改 |
| 无发热 → 高热寒战 | 血培养、感染灶评估、诊断加"脓毒症"考量 |
| 单侧 → 双侧 | 鉴别诊断重写 |

### 4. 改数值不看阈值

见上文"检验数值"。这是最高频的失败模式。

### 5. 保留或新造可识别信息

真实姓名、住院号、身份证、手机号、精确到日的就诊日期、具体到门牌号的住址、罕见病 + 特定医院的组合，都算。`deid.py` 能自动处理大部分，但**罕见病 + 小地区**这类组合需要人工判断。

### 6. 编造出处

不要写"依据《XX 指南》第 X 条"除非确实能核对到原文。教学病例可以不引用出处，编造引用比不引用更糟。

## 四、失败案例库

### 案例 1 · 数值越阈

```
原文：WBC 15.8×10⁹/L，N% 88.2% → 诊断：急性化脓性阑尾炎
改写：WBC 9.2×10⁹/L，N% 71.0% → 诊断：急性化脓性阑尾炎   ❌
```

WBC 9.2 落在正常区间，诊断依据被自己拆掉了。正确改法：WBC 13.4、N% 85.1，仍明确支持感染。

### 案例 2 · 时间线倒序

```
主诉：腹痛 3 天
现病史：2 天前开始腹痛……5 天前出现发热   ❌
```

发热早于腹痛，临床逻辑崩了。要么改主诉为"发热 5 天，腹痛 2 天"（此时主诉顺序也应调整），要么把发热改到腹痛之后。

### 案例 3 · 阴性体征误删

```
原文：Murphy 征阴性 → 鉴别诊断：急性胆囊炎
改写：删掉 Murphy 征阴性，鉴别诊断仍保留"急性胆囊炎"   ❌
```

鉴别诊断失去了排除依据。要么保留阴性体征，要么删掉该条鉴别。

### 案例 4 · 机构能力错配

```
改写：某社区卫生服务中心
正文：行腹部增强 CT 及急诊腹腔镜阑尾切除术   ❌
```

基层机构做不了。要么改回二级以上医院，要么把检查换成超声 + 转诊。

### 案例 5 · 性别翻转未连带

```
改写：32 岁女性
遗留：吸烟 20 年，20 支/日；饮酒 10 年，白酒 250 ml/日   ❌（并非绝对错误，但与本例"小学教师"设定不协调）
遗漏：无婚育史（32 岁女性入院记录必填）   ❌
```

## 五、判断口诀

改一个字段前问三句：

1. **这个字段参与诊断推理吗？** 参与 → 不动，或动了就重建整条链。
2. **它有没有阈值/分层？** 有 → 先查阈值，再决定扰动幅度。
3. **它有没有连带项？** 有 → 一次改完，别留尾巴。
